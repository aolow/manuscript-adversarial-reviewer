# Repository publication and data safety

This repository is intentionally public, but no public or open-source license is
granted at this time. Copyright remains with the project owner, all rights reserved.

Only deliberately synthetic fixtures and examples belong in source control.
Keep real manuscripts, reviewer packets, credentials, AWS configuration containing
secrets, and private outputs outside the repository or in ignored local directories.
Inspect staged files before every commit, because ignore patterns cannot identify
all forms of personal, confidential, or scientific data.

Publishing the source code does not authorize uploading third-party manuscripts
to any LLM provider. Provider use remains an explicit per-run decision.
